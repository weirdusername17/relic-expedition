# Relic Expedition

## Project Description
Relic Expedition is a turn-based console exploration game developed in Java (JDK 21). Players navigate a randomly generated 2D grid map (ranging from 5x5 to 12x12), collect all 3 relics (`R`), manage limited energy using supply caches (`C`) while avoiding hazards (`H`), and try to reach the exit (`X`) before running out of energy.

## Compile and Run Instructions
Navigate to the `src` directory in a terminal and run the following commands using JDK 21:

```bash
git clone https://github.com/weirdusername17/relic-expedition.git
cd relic-expedition/src
javac *.java
java Main
```
