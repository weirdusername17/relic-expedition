# Relic Expedition

## Project Description
Relic Expedition is a turn-based console exploration game developed in Java (JDK 21). Player navigates a randomly generated 2D grid map (ranging from 5x5 to 12x12), collect all 3 relics (`R`), manage limited energy using supply caches (`C`) while avoiding hazards (`H`), and try to reach the exit (`X`) before running out of energy.

## Compile and Run Instructions
Ensure you have **JDK 21** installed, then run the following commands from a terminal (e.g., Alacritty):

```bash
git clone https://github.com/weirdusername17/relic-expedition.git
cd relic-expedition/src
javac *.java
java Main
```
